Page de test — Widget Kadi

Cette page simule un site client qui a intégré le widget. Si tout fonctionne, une bulle de chat doit apparaître en bas de l'écran (position définie par data-position).

Avant de tester :
  1. Remplace REMPLACE_PAR_LA_VRAIE_CLE ci-dessous par la cle réelle d'un agent existant dans ta table Supabase agents.
  2. Vérifie que widget.js est bien uploadé dans ton bucket Storage.
  3. Vérifie que l'Edge Function chat-widget est déployée.
  4. Vérifie que le secret ANTHROPIC_API_KEY est configuré (sinon le fallback LLM affichera un message d'indisponibilité, mais le matching FAQ direct fonctionnera quand même).

Ouvre la console du navigateur (F12) pour voir les éventuelles erreurs réseau ou JS si la bulle n'apparaît pas.
